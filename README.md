# mac-health

Cursor skill for a read-only Mac health check: storage, memory pressure, battery, thermals, load, and recent diagnostics.

Install for yourself:

```bash
mkdir -p ~/.cursor/skills/mac-health
curl -fsSL https://raw.githubusercontent.com/raashishah/mac-health/main/SKILL.md \
  -o ~/.cursor/skills/mac-health/SKILL.md
```
